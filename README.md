# Dressrosa Fashion 🛍️

An end-to-end, full-stack e-commerce platform built to deliver a seamless shopping experience and robust administrative control. This project demonstrates practical implementation of scalable backend architecture, secure authentication workflows, and cloud deployment.

**🔴 Live Demo:** [https://dressrosa.nibrasct.in/](https://dressrosa.nibrasct.in/)

## 🛠️ Tech Stack

*   **Backend:** Node.js, Express.js
*   **Database:** MongoDB Atlas
*   **Frontend:** HTML/CSS, JavaScript, Bootstrap (or React.js if migrated)
*   **Infrastructure:** Amazon Web Services (AWS)

## 🚀 Key Features

### User-Facing (Client)
*   **Product Browsing:** Filter and search through apparel categories dynamically.
*   **Secure Authentication:** User registration and login utilizing encrypted credentials. 
*   **Optimized Password Recovery:** Engineered a secure, seamless recovery workflow (Email verification -> OTP dispatch -> Secure New Password generation).
*   **Cart & Checkout:** Persistent cart functionality with an intuitive ordering and checkout flow.

### Admin Dashboard
*   **Inventory Management:** Full CRUD operations for product listings, categorizations, and stock levels.
*   **Order Tracking:** Monitor and update the status of user orders.
*   **User Controls:** Administrative access to manage user accounts and platform security.

## 🧠 Technical Highlights & Architecture

*   **Cloud Deployment:** Fully hosted and deployed on **AWS**, managing DNS configurations and server environments to maintain uptime for the `nibrasct.in` domain.
*   **Database Engineering:** Utilized advanced MongoDB operations, including complex **aggregation pipelines, lookups, and facets** to optimize data retrieval for the frontend.
*   **Backend Performance:** Implemented efficient Node.js middleware, `fs` modules, and data streams to handle server-side logic and request parsing efficiently.
*   **Responsive Design:** Engineered strict CSS media queries to ensure the UI remains functional and aesthetically pleasing across all device sizes.
